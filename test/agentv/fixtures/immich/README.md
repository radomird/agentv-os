# Immich fixtures

Replies from Immich's own server, recorded by `test/agentv/fixtures/record/immich` in CI from its official container images, for the Immich app's contract tests (coming soon, in `agentv-app-immich`). `recording.json` says which release and when.

The server was a throwaway one with three photos of a test pattern made with ffmpeg for this, so they're ours to give away, under [CC0](https://creativecommons.org/publicdomain/zero/1.0/). Its access token is replaced with `fixture-token`.

To record them again, push a branch named `record/immich`: the Record fixtures workflow pushes fresh ones back to it.
