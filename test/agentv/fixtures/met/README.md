# MET Norway fixtures

Replies from MET Norway's Locationforecast 2.0 (`compact`), recorded on 2026-10-25 by `test/agentv/fixtures/record/met` in CI, for the weather app's tests. Each file keeps the reply and the headers the app reads.

The forecasts are MET Norway's data, under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). `zone.tab` is a few lines of the tz database's, which is public domain.

To record them again, push a branch named `record/<anything>`: the Record fixtures workflow pushes fresh ones back to it.
